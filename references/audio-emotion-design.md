# 音频情绪设计（Audio Emotion Design）

> 判据与做法。`audio_director.py` 与模板 `src/game/audio.ts` 都以此为准。

## 1. 三个层次，各管一件事

| 层 | 管什么 | 手段 |
|---|---|---|
| **音乐** | 情绪基调与紧张度 | stem 分轨，状态机切音量 |
| **音效** | 反馈与信息 | 变体、冷却、并发、距离衰减 |
| **环境** | 空间与存在感 | 持续底噪，随状态衰减/恢复 |

三层的音量必须走**独立总线**（`music` / `sfx` / `ui` / `ambience`），否则调一处会影响全部。

## 2. 自适应音乐：为什么必须是 stem

「几段不同的曲子」的做法有两个硬伤：
1. 切歌有接缝（除非做很长的交叉淡化，代价是响应变慢）
2. 情绪变化只能**硬切**，无法表达「危险正在靠近」这种连续量

**stem 分轨**：所有状态共用同一组轨道，切换状态只改各轨音量。
- 切换点听不出接缝（同一首曲子）
- 情绪是连续的（音量可以线性插值）
- 代价：需要同调同速的 5 条 loop，且必须无缝

### 五条轨的职责

| 轨 | 职责 | 典型行为 |
|---|---|---|
| `melody` | 承载主题，识别度来源 | 探索时稀疏，胜利时浮出 |
| `rhythm` | 推进感，紧张度主要来源 | 濒危时拉满 |
| `bass` | 压迫感与重量 | 危险时 +6dB |
| `percussion` | 冲击与事件强调 | 战斗时进入 |
| `atmosphere` | 空间与情绪底色 | 濒危时衰减到 15% |

### 状态配比（本作实测）

| 状态 | melody | rhythm | bass | percussion | atmosphere |
|---|---|---|---|---|---|
| exploration | 0.35 | 0 | 0.2 | 0 | 0.5 |
| danger | 0.25 | 0.35 | 0.7 | 0.1 | 0.4 |
| critical | 0.2 | 0.9 | 0.85 | 0.5 | 0.15 |
| victory | 0.85 | 0.4 | 0.5 | 0.55 | 0.3 |

**判据：任意两行必须不同，且至少有一个状态让某轨为 0。**
如果所有状态只是整体音量不同，那不是分层，是调音量 —— gate 会拦。

## 3. 动态音效的五条规则

| 规则 | 为什么 |
|---|---|
| 多变体（≥3）+ 音高/音量抖动 | 同一音效连续触发会变成机关枪 |
| 同名冷却（90ms） | 防止「一次操作触发 5 个音」 |
| 并发上限（12 / 单音 3） | 移动端 WebAudio 超过 16 声道会爆音 |
| 优先级（high 不被挤掉） | 胜负/受击的反馈永远要听得见 |
| 距离衰减 | 世界空间音效不能等响 |

## 4. 情绪化声音设计：状态驱动，不是氛围词

不合格：「濒死时音乐变得紧张」
合格：「资源 ≤20% 时：环境声 -70%，加入 60→110bpm 心跳（随资源下降加速），低频 +6dB」

| 场景 | 具体变化 |
|---|---|
| 濒临失败 | 环境声衰减 70%、心跳 60→110bpm、低频 +6dB、音乐进 critical |
| 进入安全区 | 心跳 2 秒内淡出、环境声恢复、音乐降 3dB |
| 叙事揭示 | 全部 stem 静音 0.3 秒，只留一个 bell，再整体淡入 |
| 危险接近 | rhythm/bass 增益随距离线性上升，atmosphere 反向下降 |
| Boss 前 1.5 秒 | 全部静音，制造听觉真空 |

## 5. 声音即玩法（可选，但不能强行）

判断标准：**声音是否携带视觉不提供的信息？**
- 是 → 声音是机制（回声定位：方位靠声像、距离靠延迟）
- 否 → 声音只是反馈（打击音效）

**硬要求：声音承担机制职责时，必须有 `visual_fallback`。**
静音玩家与听障玩家必须也能通关。这不是建议，`gate_check` 与专项审核都会拦。

## 6. 质检：必须实测，不能声明

`audio_director.py --qc` 用 ffmpeg 解码后逐项测量：

| 项 | 阈值 | 判据 |
|---|---|---|
| 存在性 | — | 缺失即 FAIL |
| 采样率 | ≥22050 | 过低告警 |
| 声道 | 单声道 | 立体声告警（体积翻倍） |
| 削波 | 峰值 <0.999 | 削波即 FAIL |
| 异常静音 | RMS ≥0.002 | 静音即 FAIL |
| 循环接缝 | 首尾 50ms RMS 差 ≤0.08 | 超阈告警 |
| 总体积 | ≤2MB | 超预算告警 |

本作实测：27 个文件、1455KB、缺失 0 / 削波 0 / 静音 0 / 接缝可疑 0。

## 7. 体积控制

| 素材 | 规格 | 实测 |
|---|---|---|
| 音效 | MP3 96kbps 单声道，<1s | 22 个共 280KB |
| stem | MP3 96kbps 单声道，20s 循环 | 5 条共 1175KB |
| BGM（若有） | 同 stem | — |

**不能留 wav**（体积是 mp3 的 8–10 倍），`gate_check` 直接判失败。

## 8. 反模式

| 反模式 | 后果 |
|---|---|
| 所有状态只改总音量 | 自适应是假的 |
| 同一音效无变体 | 机关枪效应 |
| 环境声永远满音量 | 关键时刻的声音传不出来 |
| 声音承载机制但没有视觉替代 | 静音玩家无法通关 |
| 只写 plan 不出音频 | 审核会判 UNVERIFIED（未验证不算通过） |
| 用 wav | 体积超标 |
