# 一页 GDD · 回声摆渡

## 一句话

你发出一声，世界亮一瞬；黑暗也听见了你。

## 核心循环（12 秒内可完成一次）

```
看见全黑 → 敲钟（-1 记忆，暴露自己） → 水面亮 1.2 秒 + 留下会腐烂的残影
        → 凭残影/声音划船 → 接到灵魂 → 送回岸边（+1 记忆，岸边亮一盏灯）
```

## 操作

| 输入 | 行为 |
|---|---|
| 方向键 / WASD | 划一格（无声） |
| 空格 / 点「敲钟」 | 敲钟：揭示 + 留残影 + 暴露 |
| 点相邻格 | 同上移动（触摸） |

## 胜负

- **胜**：把本关要求的灵魂全部送上岸
- **负**：船体 3 格耗尽（被雾里的东西抓住）

## 计分

无分数。进度 = 送达数量 + 岸边亮起的灯数。**刻意不做分数**：本作的目标是「记住代价」，不是「刷高」。

## 难度曲线（非数值）

| 关 | 记忆 | 记忆回复 | 残影寿命 | 挑战轴 |
|---|---|---|---|---|
| 1 | 5 | 11s | 10s | information（看清） |
| 2 | 4 | 13s | 8s | resource（记忆不够用） |
| 3 | 3 | **不回复** | 7s | cost（用掉就没有了） |

## 范围边界（不做什么）

- 不做多角色切换、不做装备/成长、不做联网
- 不做超过 3 关（这是 3 分钟的体验，不是长线游戏）
- 不做 AI 生图（生图通道不可用；全部程序化矢量绘制，已如实标注）
- 不做 TTS 配音（通道未配置；对白以字幕呈现）
