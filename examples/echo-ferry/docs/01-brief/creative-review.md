## 方法说明

本报告的新颖度**不是**原创性证明，而是启发式相似度分析：把方案的结构指纹
（spatial / time / info / resource / risk）与 16 个公开玩法原型比对，
重合度越高说明越可能只是换皮。结论只说明「像哪个原型、哪里需要改」。
