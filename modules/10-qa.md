# 模块 10 · 测试与试玩（qa）

**阶段**：P4 ｜ **前置**：`09-perf-audit` 通过 ｜ **产出**：`docs/07-qa/report.html`、试玩链接

## 目标

用浏览器自动化跑一遍完整走查，产出可视化报告与可分享的试玩链接。

## 步骤

### 1. 启动预览

```bash
cd <project> && npm run build:cg && npx serve dist/crazygames -l 5173
```

### 2. 自动化走查

用浏览器自动化能力（`agent-browser` / `playwright-cli`）执行：

| 检查项 | 做法 |
|---|---|
| 页面加载 | 打开 `http://localhost:5173`，断言 canvas 存在 |
| 控制台干净 | 收集 console 与 pageerror，断言零 error |
| 首屏可玩 | 截图，确认开始界面正常渲染 |
| 玩法可用 | **在 canvas 内模拟真实鼠标事件**（`page.mouse.move/down/up`），触发核心操作 |
| 状态迁移 | 断言从 Ready → Playing → GameOver 的状态变化（读取暴露的调试变量或截图比对） |
| 重开可用 | 模拟点击重开按钮，断言回到 Ready |
| 移动端视口 | 设 `375×667` 视口重跑一遍，截图确认布局正常 |

**注意**：Phaser 的 canvas 内元素无法用普通 DOM 选择器点击，必须用坐标级鼠标事件。若无法断言内部状态，在开发构建中暴露一个只读的 `window.__gameState` 供测试读取（生产构建剔除）。

### 2b. file:// 启动行为回归（★ 必做，两次踩过的坑）

**症状**：用户双击 `index.html`，页面永远停在 `Loading…`，控制台零报错。
**根因**：产物是外部 ES module，`file://` 下被 CORS（origin `null`）拒绝执行，且不产生任何错误事件。
这类 bug 的特征就是**静默**，肉眼只能看出"卡死"，所以必须自动化断言两种情形：

```bash
npm run standalone        # 产出 dist/standalone.html
npm run test:standalone   # 断言 A1-A4 + B1-B2
```

| 断言 | 内容 |
|---|---|
| A1 / A2 | 单文件版在 `file://` 下能启动，且看门狗**未**触发 |
| A3 | 无 pageerror、无失败请求（任何外部引用都会以失败请求暴露） |
| A4 | 真的出画面（**截图回灌浏览器解码**后数非黑像素） |
| B1 / B2 | 常规产物在 `file://` 下**给出提示**，且提示里有可执行动作（`standalone` / `serve`） |

**两个写测试时的坑**：

1. **不要用 `canvas.drawImage(webglCanvas)` 读回像素**：WebGL 默认不保留绘制缓冲，拿到的必然是空图
   （这个坑也踩了两次）。改用 `page.screenshot()` 拿到 PNG，再回灌浏览器用 `Image.decode()` 解出来数像素。
2. **A 组断言只证明"能起来"，不证明"能玩"**。项目落地后要在项目版脚本里补真实交互断言
   （进关卡 + 点一下真的生效），否则「能显示菜单」会被误判为通过。

### 3. 生成报告

输出 `docs/07-qa/report.html`：每项检查的通过状态、失败项的截图、控制台日志摘要。

### 4. 生成试玩链接

用「发布为应用」能力把 `dist/crazygames/` 发布为在线链接。

**用途**：
- Poki 提报要求「无需登录即可访问的可玩构建链接」
- 自己快速验证不同设备上的表现

### 5. 校验

```bash
python <skill>/scripts/gate_check.py --project <project> --stage qa
```

## 自检

- [ ] 页面加载无报错，canvas 正常渲染
- [ ] 控制台零 error（含未捕获异常）
- [ ] canvas 内点击可触发核心玩法
- [ ] 状态迁移正确：Ready → Playing → GameOver → Ready
- [ ] 移动端视口（375×667）布局正常
- [ ] **`npm run test:standalone` 全 PASS**（单文件版 file:// 可跑 + 常规产物 file:// 会给提示）
- [ ] **单文件版的真实交互已断言**（进关卡 + 操作生效，不只是"显示了菜单"）
- [ ] `report.html` 已产出
- [ ] 试玩链接可访问

## 阻断性缺陷处理

以下任一情况视为阻断，必须回退修复后重跑：

- 控制台出现未捕获异常
- 玩法无法进行（操作无响应）
- 状态卡死无法回到 Ready
- 移动端布局错乱导致不可玩
- **`file://` 下静默停在 Loading（无提示文案）** —— 说明启动看门狗失效或被删

连续 3 次失败 → 停止并上报。
